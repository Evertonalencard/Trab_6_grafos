1. O procedimento

|V|−1 porque um caminho simples tem no máximo |V|−1 arestas!

Comece com d[S] = 0 e d[v] = ∞ para os demais. Repita |V| − 1 vezes: percorra todas as rotas (u, v, w) e, se d[u] + w < d[v], atualize d[v] ← d[u] + w e π[v] ← u. A cada rodada, mais uma aresta de cada caminho mínimo fica correta.

2. Como encontrar o ciclo negativo

Terminadas as |V| − 1 rodadas, faça uma rodada extra de verificação. Se alguma rota ainda conseguir diminuir uma distância, existe ciclo de peso negativo alcançável a partir da origem.

sem ciclo negativo, nada mais poderia melhorar!

No Experimento 2, a rota D → B (−6) fecha o ciclo:

B ──3──▶ C ──2──▶ D ──(−6)──▶ B
peso total = 3 + 2 − 6 = −1

Cada volta "devolve" uma unidade de tempo ao agente. Por isso B, C e D caem 1 a cada rodada e nunca estabilizam. É a armadilha temporal: o loop de segurança do qual ele não consegue sair.

3. Como identificar os vértices do ciclo

  1. Na rodada extra, anote um vértice x que foi relaxado (atualizando π[x]).
  2. Recue |V| vezes pelos predecessores: x ← π[x]. Depois de |V| passos, é garantido estar dentro do ciclo.
  3. De x, siga π até voltar a x. Cada vértice visitado pertence ao ciclo. Inverta a lista para obter a ordem das rotas.
por que |V| passos? só há |V| vértices, então a cadeia de π precisa se repetir!
for _ in range(n):  x = pred[x]
ciclo = [x];  y = pred[x]
while y != x:
    ciclo.append(y);  y = pred[y]
ciclo.reverse()            # ['B', 'C', 'D']

Além dos vértices do ciclo, todo esconderijo alcançável a partir dele também tem custo −∞ (o agente gira quantas vezes quiser e depois segue viagem). Por isso uma busca em largura (BFS) a partir do ciclo marca todos os esconderijos-armadilha.

4. Conclusões dos experimentos

Experimento 1: S = 0, A = 4, B = 2, C = 5, D = 7, E = ∞. Menor risco: B (2), porque S → A → B (4 − 2) é melhor que a rota direta S → B (5). Maior risco: D (7). E não tem conexão com a rede.

Experimento 2: ciclo negativo B → C → D → B (peso −1). Esconderijos-armadilha: B, C e D (−∞). S = 0 e A = 4 continuam válidos; E continua sem conexão.
